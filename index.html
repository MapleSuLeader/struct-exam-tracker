第0讲 结构判定（自由度与约束）

2026-09-17

🔑 核心概念

  • 自由度（DOF）：确定体系位置所需的独立坐标数
  • 约束：减少自由度的装置
  • 多余约束：不减少自由度的约束
  • 静定/超静定：能否仅用平衡方程求解

❓ 关键问题

  1. 怎么算自由度？
  2. 约束数量与自由度的关系？
  3. 怎样判定可变/静定/超静定？
  4. 超静定次数怎么算？

一、自由度公式

刚片体系： W = 3m - (3g + 2h + b)

m刚片数（不含地基）
g单刚结数
h单铰结数
b支座链杆数

链杆体系： W = 2j - b

j铰结点数（含支座铰）
b链杆数（含支座链杆）

二、常见约束的约束数

约束类型约束数
一根链杆（二力杆）1
一个单铰2
一个刚结点3
固定铰支座2
可动铰支座1
固定端3
⚠️ 复铰：连接 n 个刚片的铰 = (n-1) 个单铰 = 2(n-1) 个约束

三、判定准则

W 值判定说明
W > 0几何可变约束不足
W = 0静定结构约束恰好
W < 0超静定多余约束，n = -W
⚠️ W ≤ 0 只是必要条件！还需检查约束布置是否合理（如三铰共线、三链杆平行则仍可变）

四、超静定次数

n = -W = (3g + 2h + b) - 3m

链杆体系：n = b - 2j

常见超静定结构：

  • 连续梁：每多一个中间支座 → +1次
  • 两端固定梁：3次超静定
  • 一端固定一端铰支：1次超静定
  • 封闭框架：3次超静定

📝 总结

一句话：自由度 W 是约束与需求的差值。W>0 可变，W=0 静定，W<0 超静定。算 W 关键是数对刚片数、铰数、链杆数，注意复铰折算。

⚠️ 易错点

  1. 复铰 = (n-1) 个单铰，别数漏
  2. W=0 不一定静定，还要看约束布置
  3. 公式里 m 不含地基，要统一

第1讲 静定梁内力计算

2026-09-17

🔑 核心概念

  • 内力：弯矩 M、剪力 V、轴力 N
  • 截面法：求内力的基本方法
  • 符号规定：正负号规则
  • 内力图：M图、V图绘制

❓ 关键问题

  1. 截面法怎么求内力？
  2. M、V 正负号怎么规定？
  3. M、V 微分关系？
  4. 叠加法怎么画 M 图？

一、截面法（核心）

Step 1 → 截：在需求内力处假想截开

Step 2 → 取：取其中一部分为隔离体

Step 3 → 平衡：列平衡方程

  • ΣFx = 0 → 轴力 N
  • ΣFy = 0 → 剪力 V
  • ΣM = 0 → 弯矩 M
💡 取荷载较少的一侧为隔离体，计算更简单

二、内力符号规定

内力正号规定
弯矩 M使梁下侧受拉为正（画在受拉侧）
剪力 V左端向上为正（顺时针转）
轴力 N拉力为正，压力为负

三、微分关系

dV/dx = -q(x)

dM/dx = V(x)

d²M/dx² = -q(x)

荷载V 图M 图
无荷载 (q=0)水平线斜直线
均布荷载斜直线抛物线（凸向荷载）
集中力 P突变(=P)折点
集中力偶 m₀无变化突变(=m₀)

四、叠加法常用值

荷载类型M 最大值
简支梁跨中集中力 PPL/4（跨中）
简支梁满跨均布 qqL²/8（跨中）
悬臂梁端部集中力 PPL（固定端）
悬臂梁满跨均布 qqL²/2（固定端）

五、多跨静定梁

💡 口诀：先附属，后基本；传力方向：附属 → 基本

📝 总结

一句话：截面法是核心，平衡方程求内力；M图画在受拉侧，V图注意正负号；利用微分关系快速画图，叠加法简化复杂荷载。

⚠️ 易错点

  1. M图画在受拉侧，不标正负
  2. 集中力偶处 M 突变，别漏
  3. 多跨静定梁从附属部分开始算
  4. V=0 对应 M 极值，可校核

第2讲 静定桁架内力计算

2026-09-17

🔑 核心概念

  • 桁架：直杆铰接，荷载作用于结点
  • 理想假设：杆件只受轴力
  • 结点法：逐结点平衡
  • 截面法：截断求解
  • 零杆：N=0 的杆件

❓ 关键问题

  1. 理想桁架假设条件？
  2. 结点法怎么逐点求解？
  3. 截面法怎么截？
  4. 怎么快速判断零杆？

一、理想桁架假设

  1. 所有结点为理想铰
  2. 杆件为直杆，轴线过铰心
  3. 荷载和反力全部作用在结点上
  4. 杆件自重忽略（或等效移至结点）

结论：每根杆件只受轴力（拉力或压力）

二、结点法

每个结点 2个方程（ΣFx=0, ΣFy=0）→ 最多求 2个未知力

步骤：

  1. 求支座反力
  2. 找只有2根未知杆的结点开始
  3. 设未知力为拉力（背离结点）
  4. 正值→拉力，负值→压力

三、零杆判定（高频考点！）

规则1：两杆结点 + 无外力 → 两杆等力

规则2：两杆结点 + 外力沿一杆 → 另一杆为零杆

规则3：三杆结点 + 无外力 + 两杆共线 → 第三杆为零杆

💡 先找零杆，可减少后续计算量！从最外围结点开始找

四、截面法

截面最多截断 3根未知杆（3个方程）

技巧：

  • 力矩法：选两未知力交点为矩心
  • 投影法：沿某方向投影消去未知力

五、方法选择

情况推荐方法
求全部杆件内力结点法
只求某几根杆截面法
截不断(>3未知)结点法配合

六、对称性利用

  • 对称荷载：对称位置杆件内力相同
  • 反对称荷载：对称位置杆件内力大小相等、符号相反

📝 总结

一句话：桁架杆件只受轴力；结点法逐点平衡（≤2未知），截面法截断求解（≤3未知杆）；先判零杆减少计算，善用对称性减半工作量。

⚠️ 易错点

  1. 零杆不是没用的杆，别随意删除
  2. 设拉力为正，负值=压力，别搞反
  3. 截面法矩心选在未知力交点
  4. 对称结构一定先用对称性简化！
