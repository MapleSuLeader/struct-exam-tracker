第0讲 结构判定（自由度与约束）

2026-09-17

🔑 核心概念

  • 自由度（DOF）：确定体系位置所需的独立坐标数
  • 约束：减少自由度的装置
  • 多余约束：不减少自由度的约束
  • 静定/超静定：能否仅用平衡方程求解

❓ 关键问题

  1. 怎么算自由度？
  2. 约束数量与自由度的关系？
  3. 怎样判定可变/静定/超静定？
  4. 超静定次数怎么算？

一、自由度公式

刚片体系： W = 3m - (3g + 2h + b)

m刚片数（不含地基）
g单刚结数
h单铰结数
b支座链杆数

链杆体系： W = 2j - b

j铰结点数（含支座铰）
b链杆数（含支座链杆）

二、常见约束类型

⚠️ 复铰：连接 n 个刚片的铰 = (n-1) 个单铰 = 2(n-1) 个约束

三、判定准则

⚠️ W ≤ 0 只是必要条件！还需检查约束布置（如三铰共线、三链杆平行则仍可变）

四、超静定次数

n = -W = (3g + 2h + b) - 3m

链杆体系：n = b - 2j

📝 总结

一句话：自由度 W 是约束与需求的差值。W>0 可变，W=0 静定，W<0 超静定。算 W 关键是数对刚片数、铰数、链杆数，注意复铰折算。

⚠️ 易错点

  1. 复铰 = (n-1) 个单铰，别数漏
  2. W=0 不一定静定，还要看约束布置
  3. 公式里 m 不含地基，要统一

📝 练习题

基础题1：计算图示体系的自由度W：刚片数 m=3，单铰数 h=3，支座链杆 b=3。判断该体系是几何不变、瞬变还是常变？

💡 查看答案

W = 3×3 - (0 + 2×3 + 3) = 9 - 9 = 0

W=0，还需检查约束布置。若三铰不共线，则几何不变（静定结构）。

陷阱题2：图示体系：4个刚片，其中有一个铰连接了3个刚片（复铰），另有2个单铰，支座链杆4根。求自由度W，判断几何性质。

💡 查看答案

复铰连接3个刚片 = (3-1)=2个单铰

总单铰数 = 2 + 2 = 4

W = 3×4 - (0 + 2×4 + 4) = 12 - 12 = 0

W=0，检查约束布置，若无三铰共线等问题，则几何不变。

进阶题3：图示简单桁架：5个结点（含2个支座铰），7根杆件（含3根支座链杆）。求自由度W，判断是否为静定结构。

💡 查看答案

链杆体系：W = 2j - b = 2×5 - 7 = 3

W=3>0，体系几何可变（常变），不是结构！

若要成为静定结构，需增加3根链杆使W=0。

第1讲 静定梁内力计算

2026-09-17

🔑 核心概念

  • 内力：弯矩 M、剪力 V、轴力 N
  • 截面法：求内力的基本方法
  • 符号规定：正负号规则
  • 内力图：M图、V图绘制

❓ 关键问题

  1. 截面法怎么求内力？
  2. M、V 正负号怎么规定？
  3. M、V 微分关系？
  4. 叠加法怎么画 M 图？

一、截面法（核心）

Step 1 → 截：在需求内力处假想截开

Step 2 → 取：取其中一部分为隔离体

Step 3 → 平衡：列平衡方程

  • ΣFx = 0 → 轴力 N
  • ΣFy = 0 → 剪力 V
  • ΣM = 0 → 弯矩 M
💡 取荷载较少的一侧为隔离体，计算更简单

dV/dx = -q(x)

dM/dx = V(x)

d²M/dx² = -q(x)

四、叠加法常用值

五、多跨静定梁

💡 口诀：先附属，后基本；传力方向：附属 → 基本

📝 总结

一句话：截面法是核心，平衡方程求内力；M图画在受拉侧，V图注意正负号；利用微分关系快速画图，叠加法简化复杂荷载。

⚠️ 易错点

  1. M图画在受拉侧，不标正负
  2. 集中力偶处 M 突变，别漏
  3. 多跨静定梁从附属部分开始算
  4. V=0 对应 M 极值，可校核

📝 练习题

基础题1：简支梁AB，跨度L=6m，跨中C点作用集中力P=20kN↓。求：(1)支座反力RA、RB；(2)C截面弯矩MC和剪力FQC；(3)绘制M图和FQ图。

💡 查看答案

对称结构对称荷载：RA = RB = P/2 = 10 kN ↑

MC = PL/4 = 20×6/4 = 30 kN·m

FQC = 0（对称点剪力为零）

M图：三角形，跨中最大30kN·m；FQ图：左段+10，右段-10

进阶题2：简支梁AB，跨度L=8m，全跨均布荷载q=5kN/m↓。求：(1)支座反力；(2)跨中弯矩和剪力；(3)距A支座2m处内力。

💡 查看答案

RA = RB = qL/2 = 5×8/2 = 20 kN ↑

跨中：M = qL²/8 = 5×64/8 = 40 kN·m，FQ = 0

距A 2m处：M = 20×2 - 5×2²/2 = 30 kN·m

FQ = 20 - 5×2 = 10 kN

挑战题3：外伸梁ABC，A固定铰，B滚动铰，AB=4m，BC=2m（外伸）。AB段q=10kN/m↓，C端P=15kN↓。求：(1)支座反力；(2)B截面左、右侧剪力；(3)AB段最大弯矩及位置。

💡 查看答案

∑MA=0：RB×4 = 10×4×2 + 15×6 → RB = 190/4 = 47.5 kN ↑

∑Fy=0：RA = 10×4 + 15 - 47.5 = 7.5 kN ↑

B左：FQ = 7.5 - 10×4 = -32.5 kN

B右：FQ = -15 kN（仅外伸段荷载）

AB段V=0处：x = 7.5/10 = 0.75m，Mmax = 7.5×0.75 - 10×0.75²/2 = 2.81 kN·m

第2讲 静定桁架内力计算

2026-09-17

🔑 核心概念

  • 桁架：直杆铰接，荷载作用于结点
  • 理想假设：杆件只受轴力
  • 结点法：逐结点平衡
  • 截面法：截断求解
  • 零杆：N=0 的杆件

❓ 关键问题

  1. 理想桁架假设条件？
  2. 结点法怎么逐点求解？
  3. 截面法怎么截？
  4. 怎么快速判断零杆？

一、理想桁架假设

  1. 所有结点为理想铰
  2. 杆件为直杆，轴线过铰心
  3. 荷载和反力全部作用在结点上
  4. 杆件自重忽略（或等效移至结点）

结论：每根杆件只受轴力（拉力或压力）

二、结点法

每个结点 2个方程（ΣFx=0, ΣFy=0）→ 最多求 2个未知力

步骤：

  1. 求支座反力
  2. 找只有2根未知杆的结点开始
  3. 设未知力为拉力（背离结点）
  4. 正值→拉力，负值→压力

三、零杆判定（高频考点！）

💡 先找零杆，可减少后续计算量！从最外围结点开始找

四、截面法

截面最多截断 3根未知杆（3个方程）

技巧：

  • 力矩法：选两未知力交点为矩心
  • 投影法：沿某方向投影消去未知力

五、方法选择

情况推荐方法
求全部杆件内力结点法
只求某几根杆截面法
截不断(>3未知)结点法配合

六、对称性利用

  • 对称荷载：对称位置杆件内力相同
  • 反对称荷载：对称位置杆件内力大小相等、符号相反

📝 总结

一句话：桁架杆件只受轴力；结点法逐点平衡（≤2未知），截面法截断求解（≤3未知杆）；先判零杆减少计算，善用对称性减半工作量。

⚠️ 易错点

  1. 零杆不是没用的杆，别随意删除
  2. 设拉力为正，负值=压力，别搞反
  3. 截面法矩心选在未知力交点
  4. 对称结构一定先用对称性简化！

📝 练习题

概念题1：对称三角形桁架：下弦A-B-C，AB=BC=4m；顶点D在B正上方高3m；杆件AD、DC（上弦），AB、BC（下弦），DB（中竖杆）；A铰支座，C滚轴支座；P=20kN作用于D点。判断哪些杆件是零杆？

💡 查看答案

零杆：DB（中竖杆）

节点B处：杆AB和杆BC共线（水平），杆DB为第三杆（竖直），节点B无外力。

根据零杆判定规则：无外力三杆节点，两杆共线，第三杆为零杆。

NDB = 0

节点法题2：简单桁架：A（左下铰支座）、B（右下滚轴支座）、C（顶部），AB=6m，C在AB中点正上方高4m；杆件AC、BC（斜杆），AB（下弦）；P=24kN作用于C点。用节点法求各杆内力。

💡 查看答案

对称性：RA = RB = 12 kN ↑

节点A：sinα = 4/5，cosα = 3/5

∑Fy=0：12 + NAC×(4/5) = 0 → NAC = -15 kN（压）

∑Fx=0：NAB + (-15)×(3/5) = 0 → NAB = 9 kN（拉）

由对称性：NBC = -15 kN（压）

截面法题3：平行弦桁架：下弦A-B-C-D（各3m），上弦E-F-G（各在AB、BC、CD中点上方），高4m；A铰支座，D滚轴支座；P1=10kN(E)、P2=20kN(F)、P3=10kN(G)。用截面法求杆BF内力。

💡 查看答案

RA = RD = 20 kN（对称荷载）

截面I-I切断EF、BF、BC，取左半部分

对B点取矩求NEF：20×3 - 10×1.5 + NEF×4 = 0 → NEF = -11.25 kN（压）

∑Fy=0：20 - 10 + NBF×sinα = 0

sinα = 4/√18.25 ≈ 0.936

NBF ≈ -10.68 kN（压）

第3讲 力法

2026-09-18

🔑 核心概念

  • 超静定结构：未知力 > 平衡方程数
  • 超静定次数：多余约束的个数
  • 力法基本未知量：多余约束力
  • 柔度系数 δ：单位力产生的位移
  • 基本结构：去掉多余约束后的静定结构

❓ 关键问题

  1. 超静定次数怎么确定？
  2. 力法的基本思路？
  3. 力法方程怎么建立？
  4. 对称结构怎么简化？

一、超静定次数确定

n = 未知力数 - 独立平衡方程数

n = 3m - 2h - r （刚架公式）

约束换算：固定端=3，固定铰=2，可动铰=1

二、力法核心思路

超静定 → 静定 → 变形协调 → 求多余力

  1. 去掉多余约束，代以多余约束力 X
  2. 列变形协调方程
  3. 解方程求 X
  4. 叠加求最终内力

三、力法方程

一次超静定：δ₁₁X₁ + Δ₁ₚ = 0

n次超静定：[δ]{X} + {Δₚ} = {0}

各项含义：

  • δᵢᵢ（主系数）：Xᵢ=1 作用下沿 Xᵢ 方向的位移，恒为正
  • δᵢⱼ（副系数）：Xⱼ=1 作用下沿 Xᵢ 方向的位移，可正可负，δᵢⱼ=δⱼᵢ
  • Δᵢₚ（自由项）：荷载作用下沿 Xᵢ 方向的位移

四、解题步骤

  1. 确定超静定次数，选基本未知量
  2. 确定基本结构（静定且几何不变）
  3. 建立力法方程
  4. 计算系数和自由项（画 M̄ᵢ 图和 Mₚ 图）
  5. 解方程求 X
  6. 叠加求内力：M = ΣM̄ᵢXᵢ + Mₚ

五、对称性利用（重要！）

荷载类型结论
对称荷载反对称多余力 = 0
反对称荷载对称多余力 = 0
💡 遇到对称结构，先判断荷载对称性，直接砍半计算！

六、支座位移和温度变化

支座位移：方程右边 Δ₁ ≠ 0，代入实际位移

温度变化：自由项增加温度项 Δᵢₜ

📝 总结

一句话：力法以多余约束力为未知量，通过变形协调方程求解；选择合适的基本结构简化计算，对称结构优先用对称性减半。

📌 核心公式

δ₁₁X₁ + Δ₁ₚ = 0

M = M̄₁X₁ + Mₚ

⚠️ 易错点

  1. 基本结构必须静定，别去掉约束后还是超静定
  2. δᵢᵢ 恒为正，δᵢⱼ 可正可负
  3. 对称结构一定要利用对称性
  4. 叠加别漏 Mₚ
  5. 支座位移问题 Δ₁ ≠ 0

📝 练习题

基础题1：两跨连续梁ABC：A端固定铰，B端中间可动铰，C端可动铰。AB=BC=4m，AB跨均布荷载q=10kN/m。用力法求B支座反力。

💡 查看答案

超静定次数：n=1

基本结构：去掉B支座，代以X₁↑

力法方程：δ₁₁X₁ + Δ₁ₚ = 0

系数计算：δ₁₁ = 8/(3EI)，Δ₁ₚ = -80/(3EI)

解：X₁ = 10 kN ↑

对称性题2：对称门式刚架，两立柱底部均为固定端，跨度L=6m，柱高H=4m，横梁均布荷载q=20kN/m。用力法求关键截面弯矩。

💡 查看答案

超静定次数：n=3（每个固定端3个约束）

对称性利用：对称结构+对称荷载→反对称多余力=0

关键弯矩：

· 横梁跨中：M = qL²/12 = 60 kN·m（下侧受拉）

· 柱顶：M = qL²/24 = 30 kN·m（内侧受拉）

· 柱底：M = qL²/24 = 30 kN·m（外侧受拉）

支座位移题3：一次超静定梁：A端固定，B端可动铰，跨度L=6m，B支座下沉Δ=10mm。用力法求B支座反力。

💡 查看答案

力法方程：δ₁₁X₁ + Δ₁ₚ = Δ_B（右边≠0！）

系数：δ₁₁ = L³/(3EI) = 72/EI，Δ₁ₚ = 0（无荷载）

解：X₁ = Δ/δ₁₁ = 10×10⁻³ × EI/72 = EI/7200 (kN)

方向向上，阻止下沉。
