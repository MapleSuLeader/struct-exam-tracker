第0讲 结构判定（自由度与约束）

2026-09-17

🔑 核心概念

  • 自由度（DOF）：确定体系位置所需的独立坐标数
  • 约束：减少自由度的装置
  • 多余约束：不减少自由度的约束
  • 静定/超静定：能否仅用平衡方程求解

❓ 关键问题

  1. 怎么算自由度？
  2. 约束数量与自由度的关系？
  3. 怎样判定可变/静定/超静定？
  4. 超静定次数怎么算？

一、自由度公式

刚片体系： W = 3m - (3g + 2h + b)

m刚片数（不含地基）
g单刚结数
h单铰结数
b支座链杆数

链杆体系： W = 2j - b

j铰结点数（含支座铰）
b链杆数（含支座链杆）

二、常见约束类型

⚠️ 复铰：连接 n 个刚片的铰 = (n-1) 个单铰 = 2(n-1) 个约束

三、判定准则

⚠️ W ≤ 0 只是必要条件！还需检查约束布置（如三铰共线、三链杆平行则仍可变）

四、超静定次数

n = -W = (3g + 2h + b) - 3m

链杆体系：n = b - 2j

📝 总结

一句话：自由度 W 是约束与需求的差值。W>0 可变，W=0 静定，W<0 超静定。算 W 关键是数对刚片数、铰数、链杆数，注意复铰折算。

  1. 复铰 = (n-1) 个单铰，别数漏

一、自由度（W）

1. 平面体系自由度公式

刚片体系：

W = 3m - (3g + 2h + b)

符号 含义

m 刚片数（不含地基）

g 单刚结数（刚片之间刚性连接）

h 单铰结数

b 支座链杆数（含固定端3、铰支座2、链杆1）

链杆体系（铰接三角形体系）：

W = 2j - b

符号 含义

j 铰结点数（含支座铰）

b 链杆数（含支座链杆）

2. 常见约束提供的约束数

约束类型 提供的约束数 减少的自由度

一根链杆（二力杆） 1 1

一个单铰 2 2

一个刚结点（单刚结） 3 3

固定铰支座 2 2

可动铰支座（辊轴支座） 1 1

固定端 3 3

> ⚠️ 复铰：连接 n 个刚片的铰 = (n-1) 个单铰 = 2(n-1) 个约束

--

二、结构判定准则

W 的值 判定结果 说明

W > 0 几何可变（机构） 约束不足，有自由度

W = 0 静定结构 约束恰好，可用平衡方程求解

W < 0 超静定结构 约束有多余，需补充变形协调方程

> ⚠️ 重要前提：W ≤ 0 只是必要条件！还需检查约束布置是否合理（几何不变性）。

>

> 即使 W ≤ 0，若约束布置不当（如三铰共线、三链杆平行等），仍可能是几何可变的。

--

三、超静定次数

n = -W = (3g + 2h + b) - 3m

或对于链杆体系：

n = b - 2j

常见超静定结构：

连续梁：每多一个中间支座 → +1次

两端固定梁：3次超静定

一端固定一端铰支梁：1次超静定

封闭框架：3次超静定

--

四、判定流程（做题步骤）

Step 1 → 确定体系类型（刚片 or 链杆）

Step 2 → 数 m（或 j）、g、h、b

Step 3 → 代入公式算 W

Step 4 → 判定：

W > 0 → 几何可变

W = 0 → 检查约束布置 → 合理 → 静定

W < 0 → 检查约束布置 → 合理 → 超静定（n = -W）

--

【总结】

> 一句话总结：自由度 W 是约束与需求的差值。W>0 可变（不够约束），W=0 静定（恰好），W<0 超静定（多余约束）。算 W 的关键是数对刚片数、铰数、链杆数，注意复铰要折算。

>

> 易错点：

> ① 复铰 = (n-1) 个单铰，别数漏

> ② W=0 不一定就是静定，还要看约束布置

> ③ 地基算不算刚片要统一（公式里 m 不含地基）

基础题1：计算图示体系的自由度W：刚片数 m=3，单铰数 h=3，支座链杆 b=3。判断该体系是几何不变、瞬变还是常变？

💡 查看答案

W = 3×3 - (0 + 2×3 + 3) = 9 - 9 = 0

W=0，还需检查约束布置。若三铰不共线，则几何不变（静定结构）。

陷阱题2：图示体系：4个刚片，其中有一个铰连接了3个刚片（复铰），另有2个单铰，支座链杆4根。求自由度W，判断几何性质。

💡 查看答案

复铰连接3个刚片 = (3-1)=2个单铰

总单铰数 = 2 + 2 = 4

W = 3×4 - (0 + 2×4 + 4) = 12 - 12 = 0

W=0，检查约束布置，若无三铰共线等问题，则几何不变。

进阶题3：图示简单桁架：5个结点（含2个支座铰），7根杆件（含3根支座链杆）。求自由度W，判断是否为静定结构。

链杆体系：W = 2j - b = 2×5 - 7 = 3

W=3>0，体系几何可变（常变），不是结构！

若要成为静定结构，需增加3根链杆使W=0。

一、截面法（核心方法）

三步走：

Step 1 → 截：在需求内力处假想截开

Step 2 → 取：取其中一部分为隔离体

Step 3 → 平衡：列平衡方程求内力

ΣFx = 0 → 轴力 N

ΣFy = 0 → 剪力 V

ΣM = 0 → 弯矩 M（对截面形心取矩）

> 💡 技巧：取荷载较少的一侧为隔离体，计算更简单

--

二、内力符号规定

弯矩 M

结构力学规定：使梁下侧受拉为正（画在受拉侧，不标正负）

也可以记：使梁产生"凹向上"变形为正

剪力 V

隔离体左端向上为正（或右端向下）

即：顺时针转为正

轴力 N

拉力为正，压力为负

--

三、荷载与内力的微分关系

(dV)/(dx) = -q(x)

(dM)/(dx) = V(x)

(d²M)/(dx²) = -q(x)

荷载情况 剪力图 V 弯矩图 M

无荷载 (q=0) 水平线 斜直线

均布荷载 (q=常数) 斜直线 二次抛物线（凸向荷载方向）

集中力 P 突变（突变值=P） 折点（斜率突变）

集中力偶 m₀ 无变化 突变（突变值=m₀）

> ⚠️ 抛物线凸向判断：均布荷载向下 → 弯矩图凸向下（像笑脸）

--

四、内力图绘制步骤

画 M 图（弯矩图）

Step 1 → 求支座反力（整体平衡）

Step 2 → 分段：按荷载变化点（集中力、集中力偶、分布荷载起终点）分段

Step 3 → 定值：

- 集中力偶处 → 左右弯矩值

- 铰支座处 → M = 0（无外力偶时）

- 集中力处 → 左右弯矩相等（折点）

Step 4 → 连线：

- 无荷载段 → 直线连接

- 均布荷载段 → 叠加法画抛物线

叠加法画弯矩图

原理：复杂荷载 = 简单荷载叠加

M(x) = M₁(x) + M₂(x) + ...

常用简单弯矩图：

荷载类型 弯矩图形状 最大值

简支梁跨中集中力 P 三角形 PL/4（跨中）

简支梁满跨均布荷载 q 抛物线 qL²/8（跨中）

悬臂梁端部集中力 P 三角形 PL（固定端）

悬臂梁满跨均布荷载 q 抛物线 qL²/2（固定端）

--

五、画 V 图（剪力图）

Step 1 → 求支座反力

Step 2 → 从左到右，逐段计算剪力

V左 = V右 - 集中力（向上外力使V减小）

Step 3 → 连线：

- 无荷载段 → 水平线

- 均布荷载段 → 斜直线（斜率 = -q）

快速检查：

集中力处 V 图突变，突变值 = 集中力大小

V = 0 处 → M 取极值

--

六、常见静定梁类型

梁类型 支座形式 静定次数

简支梁 一端固定铰 + 一端可动铰 静定

悬臂梁 一端固定 静定

外伸梁 简支 + 一端或两端外伸 静定

多跨静定梁 基本部分 + 附属部分 静定

多跨静定梁分析要点

Step 1 → 分清基本部分（能独立承载）和附属部分（依赖基本部分）

Step 2 → 从最上层附属部分开始分析

Step 3 → 逐层向下，把附属部分的反力反向加到基本部分

> 💡 口诀：先附属，后基本；传力方向：附属 → 基本

--

【总结】

> 一句话总结：截面法是核心，平衡方程求内力；M图画在受拉侧，V图注意正负号；利用微分关系快速画图，叠加法简化复杂荷载。

>

> 易错点：

> ① 弯矩图画在哪一侧要分清（受拉侧，不标正负）

> ② 集中力偶处弯矩突变，别漏

> ③ 多跨静定梁要从附属部分开始算，别从基本部分开始

> ④ V=0 对应 M 极值，可用于校核

第2讲 静定桁架内力计算

2026-09-17

🔑 核心概念

  • 桁架：直杆铰接，荷载作用于结点
  • 理想假设：杆件只受轴力
  • 结点法：逐结点平衡
  • 截面法：截断求解
  • 零杆：N=0 的杆件

❓ 关键问题

  1. 理想桁架假设条件？
  2. 结点法怎么逐点求解？
  3. 截面法怎么截？
  4. 怎么快速判断零杆？

一、理想桁架假设

  1. 所有结点为理想铰
  2. 杆件为直杆，轴线过铰心
  3. 荷载和反力全部作用在结点上
  4. 杆件自重忽略（或等效移至结点）

结论：每根杆件只受轴力（拉力或压力）

二、结点法

每个结点 2个方程（ΣFx=0, ΣFy=0）→ 最多求 2个未知力

步骤：

  1. 求支座反力
  2. 找只有2根未知杆的结点开始
  3. 设未知力为拉力（背离结点）
  4. 正值→拉力，负值→压力

三、零杆判定（高频考点！）

💡 先找零杆，可减少后续计算量！从最外围结点开始找

四、截面法

截面最多截断 3根未知杆（3个方程）

技巧：

  • 力矩法：选两未知力交点为矩心
  • 投影法：沿某方向投影消去未知力

五、方法选择

情况推荐方法
求全部杆件内力结点法
只求某几根杆截面法
截不断(>3未知)结点法配合

六、对称性利用

  • 对称荷载：对称位置杆件内力相同
  • 反对称荷载：对称位置杆件内力大小相等、符号相反

📝 总结

一句话：桁架杆件只受轴力；结点法逐点平衡（≤2未知），截面法截断求解（≤3未知杆）；先判零杆减少计算，善用对称性减半工作量。

⚠️ 易错点

  1. 零杆不是没用的杆，别随意删除
  2. 设拉力为正，负值=压力，别搞反
  3. 截面法矩心选在未知力交点
  4. 对称结构一定先用对称性简化！
📐 本讲公式与原理摘抄（来源：备考笔记 lecture-02-静定桁架内力计算.md，点击展开）

一、理想桁架基本假设

① 所有结点为理想铰（无弯矩传递）

② 所有杆件为直杆，轴线过铰心

③ 荷载和支座反力全部作用在结点上

④ 杆件自重忽略（或等效移至结点）

结论：每根杆件只受 轴力（拉力或压力），无弯矩和剪力

> 💡 实际工程中的桁架（如钢屋架、桥梁桁架）与理想桁架有偏差，但轴力仍是主要内力

--

二、结点法（Method of Joints）

原理：取每个结点为隔离体，列平面汇交力系平衡方程

F_x = 0, F_y = 0

> ⚠️ 每个结点只有 2个独立方程，因此每个结点最多求 2个未知力

步骤：

Step 1 → 求支座反力（整体平衡）

Step 2 → 找只有2根未知杆的结点开始

Step 3 → 设未知力为拉力（正方向背离结点）

Step 4 → 列 ΣFx=0, ΣFy=0 求解

正值 → 拉力

负值 → 压力

Step 5 → 依次推进，逐个结点求解

特殊结点的快速判断：

结点情况 结论

两杆结点，无外力 两杆轴力相等（同拉或同压）

两杆结点，外力沿一杆方向 另一杆为零杆

三杆结点，无外力，其中两杆共线 第三杆为零杆，共线两杆轴力相等

两杆结点，外力垂直于其中一杆 另一杆在垂直方向分力平衡外力

--

三、零杆判定（重点！考试高频）

> 零杆：轴力 N = 0 的杆件

判定规则

规则1：两杆结点 + 无外力 → 两杆等力

N₁ ←— ● —→ N₂

无外力作用

→ N₁ = N₂（同为拉力或同为压力）

规则2：两杆结点 + 外力沿一杆 → 另一杆为零杆

N₁ ←— ● —→ N₂

↑ P（沿N₂方向）

→ N₁ = 0（零杆）

→ N₂ = P

规则3：三杆结点 + 无外力 + 两杆共线 → 第三杆为零杆

N₁ ←—●—→ N₂ （N₁、N₂ 共线）

N₃ （N₃ 不共线）

无外力

→ N₃ = 0（零杆）

→ N₁ = N₂

> 💡 考试技巧：先找零杆，可以减少后续计算量！从结构最外围的结点开始找

四、截面法（Method of Sections）

原理：假想截面截断桁架，取一部分为隔离体

F_x = 0, F_y = 0, M = 0

> ⚠️ 截面最多截断 3根未知杆（3个方程求3个未知数）

> 特殊情况：若其中多数杆交于一点或互相平行，可截断更多杆

步骤：

Step 1 → 求支座反力（如需要）

Step 2 → 选择截面：截过需求内力的杆件（≤3根未知）

Step 3 → 取一侧为隔离体

Step 4 → 列平衡方程求解

优先用 ΣM=0（选未知力交点为矩心）

截面法技巧：

技巧 说明

力矩法 选两根未知力的交点为矩心，一个方程直接求第三根

投影法 沿某方向投影，消去不需要的未知力

联合法 截面法 + 结点法配合使用

一、虚功原理

基本概念

虚功：力在其虚位移上所做的功

虚位移：满足约束条件的任意微小位移（与实际荷载无关）

虚力：满足平衡条件的任意力系（与实际变形无关）

虚功原理（虚位移原理）

表述：外力虚功 = 内力虚功（变形虚功）

W_ext = W_int

Σ F_i · δ_i = (FRAC{M} + N + Qγ) ds

两种应用方式：

方式 虚设 实际 用途

虚位移原理 虚位移 实际力 求未知力（平衡问题）

虚力原理 虚力 实际位移 求未知位移（几何问题）

> 💡 核心理解：求位移用虚力原理——在所求位移方向加单位虚力

二、单位荷载法

基本公式

求结构某点K沿某方向的位移 $Δ_K$：

Δ_K = FRAC{ · M_P}EI ds + FRAC{ · N_P}EA ds + FRAC{ · Q_P}GA k ds

其中：

$M_P, N_P, Q_P$：实际荷载引起的内力

$, , $：单位虚力引起的内力

$k$：截面剪应力不均匀系数（矩形截面 $k = 6/5$）

计算步骤

Step 1 → 实际状态：在实际荷载下求内力 M_P, N_P, Q_P

Step 2 → 虚设状态：在K点沿所求位移方向加单位力 P̄ = 1

Step 3 → 求虚设状态的内力 M̄, N̄, Q̄

Step 4 → 代入公式积分

简化（梁和刚架）

对于梁和刚架，弯曲变形为主，轴向和剪切变形可忽略：

Δ FRAC{ · M_P}EI ds

--

三、图乘法

基本原理

当 $$ 图为直线时，积分可以简化为：

FRAC{ · M_P}EI ds = (1)/(EI) · · y_C

其中：

$$：$M_P$ 图的面积

$y_C$：$M_P$ 图形心对应的 $$ 图竖距

适用条件

① 杆件为等截面直杆（EI = 常数）

② 两个弯矩图中至少有一个是直线图形

③ 面积 ω 和竖距 y_C 在杆的同一侧时取正号

常见图形的面积和形心

图形 面积 ω 形心位置

三角形（底b，高h） $bh/2$ 距底端 $b/3$

二次抛物线（顶点在中点） $2bh/3$ 中点

二次抛物线（顶点在端点） $bh/3$ 距顶点 $b/4$

矩形（底b，高h） $bh$ 中点

图乘法步骤

Step 1 → 画实际荷载下的 M_P 图

Step 2 → 画单位虚力下的 M̄ 图（必为直线或折线）

Step 3 → 分段：每段内 M̄ 图为一条直线

Step 4 → 计算各段 M_P 图的面积 ω

Step 5 → 找各段 M_P 图形心，读对应的 M̄ 图竖距 y_C

Step 6 → 代入公式：Δ = Σ(ω·y_C)/(EI)

图乘法注意事项

1. 正负号判断：

ω 和 y_C 在基线同侧 → 正号

ω 和 y_C 在基线异侧 → 负号

2. 复杂图形的分解：

将 M_P 图分解为简单图形（三角形 + 抛物线）

分别图乘后叠加

3. 变截面杆：

分段处理，每段 EI 为常数

或采用等效刚度

各类结构的简化

结构类型 主要变形 简化公式

梁、刚架 弯曲变形 $Δ = FRAC{_P}EIds$

桁架 轴向变形 $Δ = Σ FRAC{_P l}EA$

组合结构 弯曲+轴向 $Δ = FRAC{_P}EIds + Σ FRAC{_P l}EA$

拱 弯曲+轴向 两项都考虑

桁架位移计算

Δ = Σ_i=1^n FRAC{_i · N_Pi · l_i}E_i A_i

> 💡 桁架每根杆件轴力为常数，积分退化为求和

五、支座位移引起的位移

当结构支座发生位移 $c_k$ 时，某点K的位移：

Δ_K = -Σ _k · c_k

其中：

$_k$：单位虚力下第k个支座的反力

$c_k$：第k个支座的实际位移

负号：虚反力方向与支座位移方向一致时做负功

> ⚠️ 支座位移不引起内力（静定结构），但会产生位移

六、温度变化引起的位移

当结构温度均匀变化 $t°$ 时：

Δ_K = Σ _k · α · t · l_k + Σ FRAC{_k · α · Δ t}h · _k

其中：

$α$：线膨胀系数

$t$：平均温度变化

$Δ t$：截面内外温差

$h$：截面高度

简化：

均匀温度变化 → 只产生轴向变形 → 桁架有影响

温差 → 产生弯曲变形 → 梁和刚架有影响

七、互等定理

1. 功的互等定理

状态I的外力在状态II的位移上做的功 = 状态II的外力在状态I的位移上做的功

W_I II = W_II I

2. 位移互等定理

δ12 = δ21

点1沿方向1的单位力在点2沿方向2产生的位移 = 点2沿方向2的单位力在点1沿方向1产生的位移

3. 反力互等定理

r₁2 = r₂1

支座1的单位位移在支座2产生的反力 = 支座2的单位位移在支座1产生的反力

> 💡 互等定理只适用于线弹性结构

八、弹性荷载法（简介）

基本思想：将结构的实际变形等效为"弹性荷载"，然后用求内力的方法求位移

M图弹性荷载：

q_弹 = (M_P)/(EI)

将 $M_P/EI$ 图作为"荷载"作用在基本结构上，求得的"弯矩"即为位移。

> 💡 弹性荷载法本质上是图乘法的另一种表现形式

四、柔度系数的含义与计算

主系数 $\delta_{ii}$

$X_i = 1$ 作用下，沿 $X_i$ 方向的位移

恒为正值（单位力做正功）

副系数 $\delta_{ij}$（i ≠ j）

$X_j = 1$ 作用下，沿 $X_i$ 方向的位移

可正可负可零

δij = Σ FRAC{_i _j}EI dx

自由项 $\Delta_{iP}$

荷载作用下，沿 $X_i$ 方向的位移

可正可负可零

计算公式：

二、静力法作影响线

基本思路：取隔离体，列平衡方程，将荷载位置 $x$ 作为变量

简支梁支座反力影响线

取 $A$ 为原点，荷载 $F_P = 1$ 距 $A$ 为 $x$

F_RA = (l-x)/(l) (0 ≤ x ≤ l)

F_RB = (x)/(l) (0 ≤ x ≤ l)

图形特征：

$F_RA$ 影响线：$A$ 点竖距为 1，$B$ 点竖距为 0 的直线

$F_RB$ 影响线：$A$ 点竖距为 0，$B$ 点竖距为 1 的直线

简支梁弯矩影响线

指定截面 $C$（距 $A$ 为 $a$，距 $B$ 为 $b$）

M_C = (b)/(l) · x & (0 ≤ x ≤ a) 荷载在C左 \\ (a)/(l) · (l-x) & (a ≤ x ≤ l) 荷载在C右

图形特征：三角形，$C$ 点竖距为 $(ab)/(l)$

简支梁剪力影响线

F_QC = -(x)/(l) & (0 ≤ x < a) 荷载在C左 \\ (l-x)/(l) & (a < x ≤ l) 荷载在C右

图形特征：两段平行线，$C$ 处有突变，左段为 $-(a)/(l)$，右段为 $(b)/(l)$

> ⚠️ 注意：剪力影响线在截面处有突变，弯矩影响线连续

伸臂梁影响线

支座反力影响线：与简支梁相同，只是荷载范围扩大到伸臂部分

伸臂部分截面影响线：在伸臂段有值，跨内段为零或线性

三、机动法作影响线

理论基础：虚功原理

基本公式：

Z(x) = -(δ_P(x))/(δ_Z)

式中：

$Z$：所求量值（反力、内力等）

$δ_P(x)$：荷载作用点的竖向位移图

$δ_Z$：与 $Z$ 相对应的广义位移

步骤：

Step 1 → 撤去与 Z 相应的约束，代以未知力 Z

使体系成为有一个自由度的机构

Step 2 → 令机构沿 Z 正方向发生单位虚位移

作出荷载作用点的竖向位移图 δ_P

Step 3 → 位移图即为影响线形状

δ_Z 以上为正，以下为负

机动法 vs 静力法：

方法 原理 特点

静力法 平衡方程 精确，可求数值

机动法 虚功原理 快速定性，适合判断最不利位置

> 💡 技巧：确定最不利荷载位置时，往往只需知道影响线轮廓，用机动法更便捷

特点：荷载通过纵梁传给横梁，再传到主梁结点

影响线特征：

在结点处与直接荷载影响线相同

在相邻结点之间为直线（不是曲线）

作法：

1. 先作直接荷载下的影响线

2. 取各结点处的竖距

一、力矩分配法的基本思想

本质：位移法的渐近解法（迭代法）

核心思路：

Step 1 → 锁住所有刚结点（加刚臂），计算各杆固端弯矩

Step 2 → 逐个放松结点：将不平衡力矩按分配系数分配给各杆

Step 3 → 分配后的弯矩向远端传递（乘以传递系数）

Step 4 → 重复 Step 2-3，直到不平衡力矩足够小

Step 5 → 叠加：最终弯矩 = 固端弯矩 + 各轮分配弯矩 + 各轮传递弯矩

> 💡 核心理解：力矩分配法 = 位移法的迭代版本。每轮"放松-分配-传递"相当于位移法方程的一次迭代

--

二、三个核心参数

1. 转动刚度 S

定义：使杆端（近端）产生单位转角所需施加的力矩

远端支承 转动刚度 S 说明

固定端 $4i$ 两端固定梁

铰支端 $3i$ 一端固定一端铰支

定向滑动 $i$ 一端固定一端滑动

自由端 $0$ 无约束

其中 $i = EI/l$ 为线刚度

2. 分配系数 μ

定义：某杆分配到的力矩占结点总不平衡力矩的比例

μ_ij = FRAC{S_ij}{Σ S_ik}

性质：

同一结点各杆分配系数之和 = 1：$Σ_k μ_ik = 1$

分配系数只与刚度比有关，与荷载无关

3. 传递系数 C

定义：远端弯矩与近端弯矩之比

C = FRAC{M_远端}{M_近端}

远端支承 传递系数 C

固定端 $1/2$

铰支端 $0$

定向滑动 $-1$

三、单结点力矩分配法

步骤（以只有一个刚结点B的连续梁为例）：

Step 1 → 锁定B（加刚臂），计算固端弯矩

M_BA^F, M_BC^F, ...（查表）

Step 2 → 计算B点不平衡力矩

M_B = ΣM_Bk^F（各杆固端弯矩之和）

Step 3 → 放松B：将 -M_B 按分配系数分配

M_Bk^分 = μ_Bk × (-M_B)

Step 4 → 向远端传递

M_kB^传 = C_kB × M_Bk^分

Step 5 → 最终杆端弯矩

M_Bk = M_Bk^F + M_Bk^分

M_kB = M_kB^F + M_kB^传

> ⚠️ 符号规定：杆端弯矩以顺时针为正

--

四、多结点力矩分配法

核心策略：逐次放松，交替进行

Step 1 → 锁定所有刚结点，计算固端弯矩

Step 2 → 选一个不平衡力矩最大的结点先放松

Step 3 → 放松该结点：分配 + 传递

Step 4 → 锁定该结点，放松下一个结点

Step 5 → 轮流放松各结点，反复迭代

Step 6 → 直到传递到各结点的不平衡力矩足够小（可忽略）

Step 7 → 叠加所有弯矩

收敛性：

每次传递后，不平衡力矩逐渐减小

因为传递系数 $|C| ≤ 1$，所以必然收敛

通常 3~5 轮即可达到工程精度

加速收敛的技巧：

从不平衡力矩最大的结点开始

相邻结点不要同时放松

对称结构可取半结构

--

五、力矩分配法 vs 位移法

比较项 力矩分配法 位移法

本质 迭代法（渐近） 精确法（解方程）

未知量 不直接求位移 求结点位移

计算过程 分配+传递，逐轮逼近 列方程，一次求解

适用 连续梁、无侧移刚架 所有结构

手算优势 计算过程规范，易校核 需解方程组

精度 取决于迭代轮数 精确

> 💡 关系：力矩分配法的分配系数和传递系数，本质上来自位移法的转角位移方程

--

六、无侧移刚架的力矩分配法

适用条件：刚架无结点线位移（侧移 = 0）

判断方法：与位移法相同（铰化法）

计算步骤：与连续梁完全相同，只是每个结点可能连接多于两根杆

注意：

柱的线刚度 $i_c = EI/h$（h为柱高）

梁的线刚度 $i_b = EI/l$（l为跨度）

分配系数计算时，所有杆（梁+柱）都要考虑

--

七、有侧移刚架的处理

力矩分配法不能直接处理有侧移的情况。

解决方法：

方法一：力矩分配法 + 位移法联合

Step 1 → 加入附加链杆阻止侧移 → 变成无侧移结构

Step 2 → 用力矩分配法计算（荷载作用）

Step 3 → 求附加链杆的反力 R₁P

Step 4 → 令附加链杆产生单位位移 Δ=1，用力矩分配法计算

Step 5 → 求附加链杆的反力 r₁₁

Step 6 → 由 r₁₁Δ + R₁P = 0 求 Δ

Step 7 → 叠加：M = Mₚ + Δ·M₁

方法二：迭代法（Cross法改进）

同时放松结点的角位移和线位移，交替迭代。

> 💡 考试中有侧移刚架一般用位移法更直接

【总结】

> 一句话总结：力矩分配法是位移法的迭代版本，通过"锁定→放松→分配→传递"的循环，逐次逼近精确解。核心参数：转动刚度S、分配系数μ、传递系数C。

> 核心公式：

> - 转动刚度：$S_固定 = 4i$，$S_铰支 = 3i$，$S_滑动 = i$

> - 分配系数：$μ_ij = S_ij / Σ S_ik$

> - 传递系数：$C_固定 = 1/2$，$C_铰支 = 0$，$C_滑动 = -1$

> - 分配弯矩：$M^分 = μ × (-M^不平衡)$

> - 传递弯矩：$M^传 = C × M^分$

> 易错点：

> ① 分配系数之和必须 = 1，可用于验算

> ② 传递系数别记混：固定端1/2，铰支0，滑动-1

> ③ 不平衡力矩 = 各杆固端弯矩之和（注意正负号！）

> ④ 放松时分配的是 -不平衡力矩（负号别漏）

> ⑤ 多结点时要轮流放松，不能同时放松相邻结点

> 考试策略：

> - 力矩分配法几乎每年必考，是拿分重点

> - 列表计算，步骤清晰，便于检查

> - 先算固端弯矩 → 再算分配系数 → 逐轮分配传递 → 最后叠加

> - 验算：结点弯矩之和 = 0

2026-10-16

🔑 核心概念

  • 单筋矩形两套流程：已知M求As / 已知As求Mu
  • 双筋截面：x>ξb·h0 且截面不能放大时引入 As′
  • x<2a′ 处理：《混规》6.2.14，对受压筋取矩
  • T形两类判别：中和轴在翼缘内=第一类
  • 翼缘计算宽度 bf′：《混规》表5.2.4 取最小值

❓ 关键问题

  1. 配筋式 x 的求法和复核式差在哪？
  2. 受压钢筋充分利用的前提条件是什么？
  3. x<2a′ 时公式里为什么出现 h−as−as′？
  4. 配筋计算和截面复核的判别式各用哪个？
  5. bf′ 按哪三个因素确定？

一、单筋矩形截面：两类计算流程

配筋计算（已知M求As）：

x = h0 − √[h0² − 2γ0M/(α1·fc·b)]，要求 x ≤ ξb·h0

As = α1·fc·b·x / fy，再校核 As ≥ ρmin·b·h

截面复核（已知As求Mu）：

x = fy·As/(α1·fc·b)；x>ξb·h0 时取 x=ξb·h0

Mu = α1·fc·b·x·(h0 − x/2)，验算 γ0·M ≤ Mu

⚠️ x>ξb·h0 且截面/混凝土等级不能改 → 转双筋；抗震计算把 γ0M 换成 γRE·M（γRE=0.75 受弯）

二、双筋矩形截面（《混规》6.2.10）

ΣN=0：α1·fc·b·x + fy′·As′ = fy·As

ΣM=0：γ0·M ≤ α1·fc·b·x·(h0−x/2) + fy′·As′·(h0−as′)

适用前提：x ≤ ξb·h0 且 x ≥ 2a′（保证受压筋屈服、应力取 fy′）

配筋流程：M1 = γ0M − fy′As′(h0−as′) → 用 M1 按单筋求 x → As = (α1·fc·b·x + fy′·As′)/fy

⚠️ 抗震框架梁端截面附加要求：x ≤ 0.25h0（一级）、x ≤ 0.35h0（二、三级）

三、x<2a′ 的处理（《混规》6.2.14）

x<2a′ → 受压筋应变小、不屈服 → 近似取 x=2a′，弯矩对受压筋合力点取矩：

配筋：As = γ0M / [fy·(h − as − as′)]

复核：Mu = fy·As·(h − as − as′)（抗震再除 γRE）

四、T形截面两类判别与计算（《混规》6.2.11）

判别：中和轴在翼缘内（x ≤ hf′）= 第一类，按宽 bf′ 的矩形算；中和轴入肋（x>hf′）= 第二类

配筋式判别：α1·fc·bf′·hf′·(h0−hf′/2) ≥ γ0M → 第一类

复核式判别：α1·fc·bf′·hf′ ≥ fy·As → 第一类

第二类配筋：M1 = α1·fc·(bf′−b)·hf′·(h0−hf′/2)；x = h0 − √[h0² − 2(γ0M−M1)/(α1·fc·b)]

As = α1·fc·[b·x + (bf′−b)·hf′] / fy

箱形、工字形、槽形、倒L形均可等效为T形处理

五、翼缘计算宽度 bf′（《混规》表5.2.4）

三因素控制，取最小值：①计算跨度 l0：肋形梁 l0/3，倒L形肋形梁 l0/6；②梁肋净距 sn：b+sn（肋形）、b+sn/2（倒L）；③翼缘高度 hf′/h0：≥0.1 时 b+12hf′；0.05~0.1 时肋形 b+12hf′/独立梁 b+6hf′；<0.05 时肋形 b+12hf′/独立 b+5hf′

影响翼缘有效性的本质：离肋越远的翼缘参与受力越差（剪滞）

⚠️ 独立梁（不与楼板整浇）受压翼缘可能沿纵肋开裂时，计算宽度只取 b

📝 总结

一句话：正截面承载力全是"两个平衡方程+适用条件"的变体——单筋是母版（x≤ξb·h0、As≥ρmin·bh）；双筋加一项 fy′As′(h0−as′)，x≥2a′ 才计受压筋，否则对受压筋取矩；T形先判类型，第一类当 bf′ 宽的矩形，第二类从弯矩里先扣掉翼缘挑出部分 (bf′−b)hf′，bf′ 查表5.2.4取最小。

⚠️ 易错点

  1. 配筋式与复核式的 T形判别式不同（一个带 h0−hf′/2，一个不带）
  2. x<2a′ 用 h−as−as′ 力臂，不是 h0−as′
  3. 抗震端截面 x≤0.25/0.35h0 是延性要求，比 ξb 严
  4. bf′ 三种情况取最小值，不是最大值

e0=M/N，ea=max(20, h/30)，ei=e0+ea；先按 6.2.4（附录B）判断二阶效应是否放大 M

🔑 核心概念

  • 轴拉 6.2.22：γ0N ≤ fyAs+fpyAp，全筋屈服
  • 偏拉判别：e0 与 h/2−as 比大小
  • 小偏拉：两侧筋均屈服、混凝土不参与

❓ 关键问题

  1. 为什么轴拉公式没有混凝土项？
  2. 大小偏拉怎么分界？
  3. Wt 公式？
  4. ζ 的取值范围？
  5. 受扭纵筋为何沿周边+四角布置？

一、轴心受拉（6.2.22）

γ0N ≤ fy·As + fpy·Ap——开裂后混凝土退出工作，全部纵向钢筋受拉屈服

一侧 ρmin = max(0.2%, 45ft/fy%)（8.5.1）；抗震 γRE=0.85

二、偏心受拉（6.2.23）

e0=M/N < h/2−as（N 作用在两排筋之间）→ 小偏拉；e0 ≥ h/2−as → 大偏拉

小偏拉：As = γ0N·e/[fy(h0−a′s)]，e = e0+h/2−a′s（对 A′s 合力点取矩）；求 A′s 对 As 取矩同理

大偏拉：形式同大偏压（有受压区），按 6.2.23-3/4

最小配筋率：小偏拉按全截面 A；大偏拉按 A−(bf′−b)hf′

⚠️ 判别分界是 h/2−as（N 作用点位置），不是 ξb

三、纯扭承载力（6.4.4）

平衡扭转（雨篷梁）：扭矩与抗扭刚度无关，必须计算；协调扭转（框架边梁）：可仅构造增配

矩形 Wt = b²(3h−b)/6；T 形/工字形分块（腹板+翼缘），扭矩按各块 Wt 比例分配

T ≤ 0.35ft·Wt + 1.2√ζ·fyv·(Ast1/s)·Acor；ζ 纵筋与箍筋匹配系数，取 0.6~1.7（手算常设 1.0 再校核）

截面限制（6.4.1）：T/(0.8Wt) ≤ 0.25βc·fc（hw/b≤4）；Acor=箍筋中心线围合面积

四、弯剪扭叠加

箍筋：(Asv/s)总 = 受剪所需 + 受扭 2Ast1/s（扭矩由两侧肢承担）；纵筋=受弯+受扭 Ast（周边均布、四角必设）

受扭纵筋 ρtl,min = 0.35ft/fy（9.2.5）；弯剪扭箍筋 ρsv,min = 0.28ft/fyv（9.2.10，比纯剪 0.24 高）

剪扭相关性：βt=1.5/(1+0.5VWt/(Tbh0))，混凝土项分别折减后叠加（6.4.8~6.4.10）

⚠️ fyv>360 仍取 360（4.2.3 受剪/受扭/受冲切）

📝 总结

一句话：受拉构件"混凝土退场、钢筋说话"——轴拉全筋屈服、小偏拉两侧筋各自取矩；扭转三件套：Wt=b²(3h−b)/6 → T≤0.35ftWt+1.2√ζfyv(Ast1/s)Acor（ζ 0.6~1.7）→ 弯剪扭用 βt 折减、箍筋叠加 2Ast1/s、构造下限 0.28ft/fyv。

🔑 核心概念

  • σcon 上限：钢绞线/钢丝 0.75fptk，螺纹筋 0.85fpyk
  • 六项损失：σl1锚具 σl2摩擦 σl3温差 σl4松弛 σl5收缩徐变 σl6局压
  • 两批组合：先张第一批=1+2+3+4；后张第一批=1+2
  • 两阶段 σpc：σpcI 第一批；σpcII 全部损失
  • 裂缝控制三级：一级 σck−σpc≤0；二级 ≤ftk；三级限宽

❓ 关键问题

  1. 哪些损失先张法独有？
  2. σcon 何时可 +0.05fptk？
  3. 第一批/第二批按什么时点分？
  4. 三级抗裂各用什么荷载组合？
  5. 先张法放张强度要求？

一、张拉控制应力 σcon（10.1.3）

消除应力钢丝、钢绞线：0.4fptk ≤ σcon ≤ 0.75fptk；中强度钢丝 ≤0.7fptk；预应力螺纹钢筋 0.5~0.85fpyk

可放宽 +0.05fptk：为提高施工阶段抗裂设于受压区的筋；或部分抵消松弛/摩擦/分批张拉/温差损失

二、六项损失与组合（10.2.1）

σl1 锚具变形内缩｜σl2 摩擦｜σl3 蒸养温差（仅先张法）｜σl4 松弛｜σl5 收缩徐变｜σl6 局部挤压（螺旋配筋环形构件 d≤3m）

组合：先张第一批（预压前）σl1+σl2+σl3+σl4、第二批 σl5；后张第一批 σl1+σl2、第二批 σl4+σl5+σl6

损失过小兜底：先张法 ≥100N/mm²，后张法 ≥80N/mm²

⚠️ σl4 归属分批是先张/后张差异的核心——真题爱考

三、两阶段预压应力

σpcI（施工/预压阶段）：仅第一批损失；σpcII（使用阶段）：全部损失

预压阶段 σpc ≤ 0.5f′cu（防局压/预拉开裂）；求 σpc 时损失按 10.2.5 组合取值

四、抗裂验算与裂缝控制等级（3.4.4/7.1.1）

一级（全预应力）：标准组合 σck − σpc ≤ 0——受拉边不出现拉应力

二级：标准组合 σck − σpc ≤ ftk——出现拉应力但不裂通

三级（部分预应力）：wmax ≤ 限值；预应力裂缝按标准组合，二a类环境按准永久组合 σcq−σpc ≤ ftk

⚠️ 组合选择高频考点：钢筋混凝土=准永久；预应力三级裂缝=标准组合

五、构造要点（10.3）

锚固区：锚垫板下局部受压验算 + 间接钢筋（螺旋箍/焊网）防劈裂

先张法放张：混凝土强度 ≥ 75% 设计强度；后张法：波纹管成孔、有黏结灌浆、束间距与保护层按 10.3

预应力构件仍须配置受拉侧普通钢筋最小配筋（防一裂即断）；长期反拱+挠度按第7讲刚度概念叠加

📝 总结

一句话：预应力 = σcon 上限（0.75fptk）− 六项损失分两批组合（先张 1234｜后张 12 为第一批）→ σpcI（预压阶段，≤0.5f′cu）与 σpcII（使用阶段）→ 抗裂三级（σck−σpc 比 0 / ftk / 裂缝限宽）；σl3 先张独有、σl6 环形专属、损失下限 100/80。

⚠️ 易错点

  1. 先张/后张分批混淆
  2. σcon+0.05 的适用条件
  3. 一级/二级同用标准组合但限值不同
  4. 二a类环境预应力改准永久

2026-10-26

🔑 核心概念

  • 冲切公式：Fl ≤ 0.7βh·ft·η·um·h0（6.5.1，无抗冲切钢筋）
  • η 取小：η=min(η1,η2)，η1=0.4+1.2/βs，η2=0.5+αs·h0/(4um)
  • αs：中柱40、边柱30、角柱20；βs=hc/bc 限2~4（圆形取2）
  • 有抗冲切筋：0.5ft项+0.8fyvAsvu+0.8fyAsbu·sinα；fyv>360取360
  • 局压：βl=√(Ab/Al)；截面限制1.35βcβlfcAln；间接筋0.9(βcβlfc+2αρvβcor·fyv)Aln

❓ 关键问题

  1. Fl 为什么要扣锥体内板荷载？
  2. 孔洞影响 um 怎么扣？
  3. 不平衡弯矩如何等效为 Fl,eq？
  4. 抗震等级对 Fl,eq 增大系数？
  5. 局压 Ab 的"同心对称"原则？
  6. Acor≤1.25Al 时如何处理？

一、无抗冲切钢筋的板（混规6.5.1/6.5.2）

受冲切承载力：Fl ≤ 0.7βh·ft·η·um·h0；βh：h≤800取1.0，h≥2000取0.9，线性插值

um 临界截面周长（局部荷载边缘外 h0/2）：矩形 2[(bc+h0)+(hc+h0)]；方形 4(bc+h0)；圆形 2π(r+h0)

η=min(η1,η2)：η1=0.4+1.2/βs（βs=hc/bc，限2~4，圆形βs=2）；η2=0.5+αs·h0/(4um)，αs：中柱40、边柱30、角柱20

冲切力 Fl=柱轴力层间差 − q×冲切锥体底面积（荷载面积外扩2h0：方形(bc+2h0)²、矩形(bc+2h0)(hc+2h0)）

孔洞：洞边至局部荷载/集中反力边缘 ≤6h0 时，um 扣除局部荷载中心至孔洞外边切线间长度（l1≤l2：l4=(b+h0)/(b+2l)·l2；l1>l2：用√(l1l2)）

⚠️ 题目问"冲切力Fl"还是"受冲切承载力0.7βhftηumh0"，看清再算；F[l]是承载力、Fl是荷载效应

二、冲切位置与基础冲切

柱对托板冲切：有效高度 h0；托板对板冲切：取 h01（两层分别验算，各用各自临界面）

非矩形（异形）柱：um 取凸折线、折角≤180°，临界面离柱边允许>h0/2，取最小周长

阶形基础（6.5.5）：柱与基础交接处、基础变阶处两个截面验算 Fl ≤ 0.7βh·ft·bm·h0（bm 为平均宽度，冲切锥沿坡面）

三、配置箍筋/弯起钢筋（6.5.3/6.5.4，构造9.1.11）

截面限制（双控上限）：Fl ≤ 1.2ft·η·um·h0，防止箍筋不能充分发挥、斜裂缝过大

承载力：Fl ≤ (0.5ft+0.25σpc,m)η·um·h0 + 0.8fyvAsvu + 0.8fyAsbu·sinα；σpc,m 非预应力取0

fyv>360MPa 时取 360；Asvu/Asbu=与45°冲切锥体斜截面相交的全部箍筋/弯起筋面积

锥体以外截面（6.5.4）：按6.5.1再验算，um 取最外排抗冲切钢筋周边以外 0.5h0 处最不利周长

构造（9.1.11）：抗冲切箍筋 d≥6mm、间距 s≤min(h0/3, 100mm)？教材口径 s≤h0/3；弯起筋 d≥12mm、每向≥3根

⚠️ 已知Fl求箍筋：Asvu=(Fl−0.5ftηumh0)/(0.8fyv)，再按四周总肢数 n·Asv1≥Asvu 配筋

四、板柱节点不平衡弯矩（附录F + 抗震11.9.3）

节点传递不平衡弯矩 Munb 时，用等效集中反力：Fl,eq = Fl + τmax·um·h0（把锥体斜面化为临界截面垂直截面，Munb 产生的竖向剪应力线性分布，取 τmax 折算附加集中反力）

Munb 取对临界截面周长重心轴（轴2）的矩 = 对柱重心轴（轴1）的弯矩 + Fl 对该轴取矩；两弯矩同向取加、反向取减；计算系数 αo 按 F.0.2，中/边/角柱参数见图 F.0.1

边柱/角柱有悬臂板时：可能按边/角柱临界面，也可能按中柱锥体，计算比较取不利（F.0.4）

地震组合（11.9.3）：Fl,eq 乘增大系数——一、二、三级抗震等级分别取 1.7、1.5、1.3；配抗冲切钢筋时锥体以外截面按 6.5.4 式验算（um 取最外排筋外 0.5h0）

⚠️ 借鉴 ACI 318 方法；忽略临界截面水平剪应力（近似略去 h0³ 项）

五、局部受压（6.6）

机理：外围混凝土"套箍"→局部区三向受压→局压强度远高于轴压，提高随 Ab/Al 增大

βl=√(Ab/Al)；Ab（6.6.2）"同心、对称"：与局压面同重心，沿各边向外扩大有效距离不超过受压面短边 b（圆形承压板可沿周边扩大一倍直径）；边角局压 βl=1.0；算 βl 不扣除孔道面积

截面限制（6.6.1）：Fl ≤ 1.35βcβl·fc·Aln；βc：≤C50取1.0，C80取0.8（插值）

配置方格网/螺旋间接钢筋（6.6.3）：Fl ≤ 0.9(βcβlfc + 2α·ρv·βcor·fyv)Aln；α：≤C50取1.0，C80取0.85；βcor=√(Acor/Al)，Acor>Ab时取Ab；Acor≤1.25Al 时不考虑间接钢筋提高

ρv：方格网 (n1As1l1+n2As2l2)/(Acor·s)；螺旋式 4Ass1/(dcor·s)；长短向配筋相差过大受限时钢筋强度不能充分发挥

素混凝土局压（附录D.5.1）：ω 均布取1.0、梁/过梁端部支承（非均匀）取0.75；锚头下局压：预应力作荷载效应对不利时分项系数1.2（10.1.2）；牛腿局压见构造（8.2.2，第7讲）

⚠️ 2013二级真题：a=300、b=200 居中 → Ab=(300+2×200)×(3×200)=420000，βl=√(Ab/Al)=2.65

一句话：冲切 = 0.7βhftηumh0（um在h0/2处、η取η1η2小者、Fl扣锥体内荷载、洞口≤6h0要扣周长）；配抗冲切筋双控（1.2ft上限+0.5ft+0.8fyvAsvu+0.8fyAsbu·sinα，fyv≤360）；板柱节点有不平衡弯矩换 Fl,eq=Fl+τmax·um·h0、抗震乘1.7/1.5/1.3；局压 = βl=√(Ab/Al)（同心对称、边角取1.0）+ 截面限制1.35βcβlfcAln + 间接筋0.9(βcβlfc+2αρvβcor·fyv)Aln（Acor≤1.25Al不考虑）。
