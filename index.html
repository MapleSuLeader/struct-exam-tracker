第0讲 结构判定（自由度与约束）

2026-09-17

🔑 核心概念

  • 自由度（DOF）：确定体系位置所需的独立坐标数
  • 约束：减少自由度的装置
  • 多余约束：不减少自由度的约束
  • 静定/超静定：能否仅用平衡方程求解

❓ 关键问题

  1. 怎么算自由度？
  2. 约束数量与自由度的关系？
  3. 怎样判定可变/静定/超静定？
  4. 超静定次数怎么算？

一、自由度公式

刚片体系： W = 3m - (3g + 2h + b)

m刚片数（不含地基）
g单刚结数
h单铰结数
b支座链杆数

链杆体系： W = 2j - b

j铰结点数（含支座铰）
b链杆数（含支座链杆）

二、常见约束类型

⚠️ 复铰：连接 n 个刚片的铰 = (n-1) 个单铰 = 2(n-1) 个约束

三、判定准则

⚠️ W ≤ 0 只是必要条件！还需检查约束布置（如三铰共线、三链杆平行则仍可变）

四、超静定次数

n = -W = (3g + 2h + b) - 3m

链杆体系：n = b - 2j

📝 总结

一句话：自由度 W 是约束与需求的差值。W>0 可变，W=0 静定，W<0 超静定。算 W 关键是数对刚片数、铰数、链杆数，注意复铰折算。

⚠️ 易错点

  1. 复铰 = (n-1) 个单铰，别数漏
  2. W=0 不一定静定，还要看约束布置
  3. 公式里 m 不含地基，要统一

📝 练习题

基础题1：计算图示体系的自由度W：刚片数 m=3，单铰数 h=3，支座链杆 b=3。判断该体系是几何不变、瞬变还是常变？

💡 查看答案

W = 3×3 - (0 + 2×3 + 3) = 9 - 9 = 0

W=0，还需检查约束布置。若三铰不共线，则几何不变（静定结构）。

陷阱题2：图示体系：4个刚片，其中有一个铰连接了3个刚片（复铰），另有2个单铰，支座链杆4根。求自由度W，判断几何性质。

💡 查看答案

复铰连接3个刚片 = (3-1)=2个单铰

总单铰数 = 2 + 2 = 4

W = 3×4 - (0 + 2×4 + 4) = 12 - 12 = 0

W=0，检查约束布置，若无三铰共线等问题，则几何不变。

进阶题3：图示简单桁架：5个结点（含2个支座铰），7根杆件（含3根支座链杆）。求自由度W，判断是否为静定结构。

💡 查看答案

链杆体系：W = 2j - b = 2×5 - 7 = 3

W=3>0，体系几何可变（常变），不是结构！

若要成为静定结构，需增加3根链杆使W=0。

第2讲 静定桁架内力计算

2026-09-17

🔑 核心概念

  • 桁架：直杆铰接，荷载作用于结点
  • 理想假设：杆件只受轴力
  • 结点法：逐结点平衡
  • 截面法：截断求解
  • 零杆：N=0 的杆件

❓ 关键问题

  1. 理想桁架假设条件？
  2. 结点法怎么逐点求解？
  3. 截面法怎么截？
  4. 怎么快速判断零杆？

一、理想桁架假设

  1. 所有结点为理想铰
  2. 杆件为直杆，轴线过铰心
  3. 荷载和反力全部作用在结点上
  4. 杆件自重忽略（或等效移至结点）

结论：每根杆件只受轴力（拉力或压力）

二、结点法

每个结点 2个方程（ΣFx=0, ΣFy=0）→ 最多求 2个未知力

步骤：

  1. 求支座反力
  2. 找只有2根未知杆的结点开始
  3. 设未知力为拉力（背离结点）
  4. 正值→拉力，负值→压力

三、零杆判定（高频考点！）

💡 先找零杆，可减少后续计算量！从最外围结点开始找

四、截面法

截面最多截断 3根未知杆（3个方程）

技巧：

  • 力矩法：选两未知力交点为矩心
  • 投影法：沿某方向投影消去未知力

五、方法选择

情况推荐方法
求全部杆件内力结点法
只求某几根杆截面法
截不断(>3未知)结点法配合

六、对称性利用

  • 对称荷载：对称位置杆件内力相同
  • 反对称荷载：对称位置杆件内力大小相等、符号相反

📝 总结

一句话：桁架杆件只受轴力；结点法逐点平衡（≤2未知），截面法截断求解（≤3未知杆）；先判零杆减少计算，善用对称性减半工作量。

⚠️ 易错点

  1. 零杆不是没用的杆，别随意删除
  2. 设拉力为正，负值=压力，别搞反
  3. 截面法矩心选在未知力交点
  4. 对称结构一定先用对称性简化！

第3讲 结构位移计算

2026-09-27

🔑 核心概念

  • 虚功原理：外力虚功 = 内力虚功
  • 单位荷载法：在所求位移方向加单位力
  • 图乘法：用图形面积和形心竖距代替积分
  • 互等定理：功的互等、位移互等、反力互等
  • 弹性荷载法：将实际变形等效为荷载

❓ 关键问题

  1. 虚功原理的内容和适用条件？
  2. 单位荷载法怎么求指定截面位移？
  3. 图乘法的适用条件和步骤？
  4. 支座位移和温度变化怎么求位移？
  5. 互等定理有哪些？怎么应用？

一、虚功原理

外力虚功 = 内力虚功

ΣFi·δi = ∫(Mκ̄ + Nε̄ + Qγ̄)ds

方式虚设实际用途
虚位移原理虚位移实际力求未知力
虚力原理虚力实际位移求未知位移
💡 求位移用虚力原理——在所求位移方向加单位虚力

二、单位荷载法

ΔK = ∫M̄MP/(EI)ds + ∫N̄NP/(EA)ds + ∫kQ̄QP/(GA)ds

简化：梁和刚架可忽略轴向和剪切变形

Δ ≈ ∫M̄·MP/(EI) ds

三、图乘法

∫M̄MP/(EI) ds = ω·yC/(EI)

适用条件：

  • 杆件为等截面直杆（EI=常数）
  • 两个弯矩图中至少有一个是直线图形
  • 面积ω和竖距yC在杆的同一侧时取正号
图形面积 ω形心位置
三角形bh/2距底端 b/3
二次抛物线（顶点在中点）2bh/3中点
二次抛物线（顶点在端点）bh/3距顶点 b/4
⚠️ 正负号：ω和yC同侧为正，异侧为负

四、支座位移引起的位移

ΔK = −ΣR̄k·ck

其中 R̄k 为单位虚力下第k个支座的反力

💡 支座位移不引起内力（静定结构），但会产生位移

五、互等定理

定理内容
功的互等WI→II = WII→I
位移互等δ12 = δ21
反力互等r12 = r21
⚠️ 互等定理只适用于线弹性结构

📝 总结

一句话：结构位移计算以虚功原理为基础，单位荷载法是核心方法，图乘法是实用工具。

📌 核心公式

单位荷载法：Δ = ∫M̄MP/(EI)ds

图乘法：Δ = ω·yC/(EI)

桁架位移：Δ = ΣN̄NPl/(EA)

支座位移：Δ = −ΣR̄k·ck

⚠️ 易错点

  1. 图乘法要求至少一个M图为直线
  2. 图乘正负号：同侧为正，异侧为负
  3. 抛物线形心位置别记错
  4. 支座位移公式有负号
  5. 桁架位移是求和不是积分

第4讲 力法

2026-09-18

🔑 核心概念

  • 超静定结构：未知力 > 平衡方程数
  • 超静定次数：多余约束的个数
  • 力法基本未知量：多余约束力
  • 柔度系数 δ：单位力产生的位移
  • 基本结构：去掉多余约束后的静定结构

❓ 关键问题

  1. 超静定次数怎么确定？
  2. 力法的基本思路？
  3. 力法方程怎么建立？
  4. 对称结构怎么简化？

一、超静定次数确定

n = 未知力数 - 独立平衡方程数

n = 3m - 2h - r （刚架公式）

约束换算：固定端=3，固定铰=2，可动铰=1

二、力法核心思路

超静定 → 静定 → 变形协调 → 求多余力

  1. 去掉多余约束，代以多余约束力 X
  2. 列变形协调方程
  3. 解方程求 X
  4. 叠加求最终内力

三、力法方程

一次超静定：δ₁₁X₁ + Δ₁ₚ = 0

n次超静定：[δ]{X} + {Δₚ} = {0}

各项含义：

  • δᵢᵢ（主系数）：Xᵢ=1 作用下沿 Xᵢ 方向的位移，恒为正
  • δᵢⱼ（副系数）：Xⱼ=1 作用下沿 Xᵢ 方向的位移，可正可负，δᵢⱼ=δⱼᵢ
  • Δᵢₚ（自由项）：荷载作用下沿 Xᵢ 方向的位移

四、解题步骤

  1. 确定超静定次数，选基本未知量
  2. 确定基本结构（静定且几何不变）
  3. 建立力法方程
  4. 计算系数和自由项（画 M̄ᵢ 图和 Mₚ 图）
  5. 解方程求 X
  6. 叠加求内力：M = ΣM̄ᵢXᵢ + Mₚ

荷载类型结论
对称荷载反对称多余力 = 0
反对称荷载对称多余力 = 0
💡 遇到对称结构，先判断荷载对称性，直接砍半计算！

温度变化：自由项增加温度项 Δᵢₜ

一句话：力法以多余约束力为未知量，通过变形协调方程求解；选择合适的基本结构简化计算，对称结构优先用对称性减半。

一、转角位移方程

两端固定梁：

MAB = 4iθA + 2iθB - 6iΔ/L

MBA = 2iθA + 4iθB - 6iΔ/L

一端固定一端铰支：

MAB = 3iθA - 3iΔ/L

线刚度 i = EI/L：杆件抗弯刚度除以杆长

💡 记忆口诀：4-2-6（两端固定），3-0-3（一端铰支）
A θB L MAB MBA 一端铰支梁 θA L MAB = 3iθA

二、基本未知量确定

未知量类型确定方法
角位移 θ刚结点数（每个刚结点1个）
线位移 Δ独立线位移数（铰接点简化法）
💡 线位移数 = 铰接体系自由度（将刚架所有刚结点改为铰结点后的自由度）

三、位移法方程

结点平衡方程：ΣM结点 = 0

剪力平衡方程：ΣFx = 0 或 ΣFy = 0

方程形式：

  • kii（主刚度系数）：单位位移δi=1产生的结点力
  • kij（副刚度系数）：单位位移δj=1产生的结点力
  • Ri（自由项）：荷载产生的结点力

四、解题步骤

  1. 确定基本未知量（角位移θ + 线位移Δ）
  2. 列转角位移方程，表达各杆端弯矩
  3. 建立平衡方程（结点平衡 + 剪力平衡）
  4. 解方程求位移未知量
  5. 代回转角位移方程求杆端弯矩
  6. 画内力图

五、对称性利用

荷载类型变形特点半结构取法
对称荷载对称轴处无转角、无水平位移对称轴处加定向支座
反对称荷载对称轴处无竖向位移对称轴处加可动铰支座
💡 对称结构先判断荷载对称性，取半结构计算，未知量减半！

六、力法 vs 位移法

对比项力法位移法
基本未知量多余约束力结点位移
适用范围超静定次数少超静定次数多、刚架
方程类型变形协调平衡方程
系数含义柔度系数δ刚度系数k
💡 经验：超静定次数少用力法，结点多用位移法；刚架优先位移法

📝 总结

一句话：位移法以结点位移为未知量，通过转角位移方程和平衡方程求解；刚架、超静定次数多时优先使用。

第6讲 影响线

2026-09-24

🔑 核心概念

  • 影响线：单位移动荷载下某量值变化规律的图形
  • 静力法：列平衡方程，x为变量
  • 机动法：虚功原理，撤约束作位移图
  • 最不利荷载：使某量达最大的荷载位置
  • 临界荷载：使量值达极值的荷载

❓ 关键问题

  1. 影响线与内力图有什么区别？
  2. 静力法作影响线的步骤？
  3. 机动法的原理和步骤？
  4. 怎么确定最不利荷载位置？
  5. 绝对最大弯矩怎么求？

一、影响线的概念

定义：表示单位移动荷载（FP=1）作用下，某指定截面某量值变化规律的图形

比较项内力图影响线
荷载固定荷载单位移动荷载
横坐标截面位置荷载作用位置
纵坐标该截面内力值指定截面在荷载位于此位置时的内力值
用途固定荷载下内力移动荷载下最不利内力
💡 核心理解：内力图是"荷载固定，看各截面"；影响线是"截面固定，看荷载移动"
⚠️ 应用条件：只有叠加原理成立时，才能引入影响线概念

二、静力法作影响线

基本思路：取隔离体，列平衡方程，将荷载位置 x 作为变量

简支梁支座反力

FRA = (l−x)/l   (0≤x≤l)

FRB = x/l   (0≤x≤l)

FRA：A点竖距1，B点竖距0的直线

FRB：A点竖距0，B点竖距1的直线

简支梁弯矩影响线（截面C，距A为a，距B为b）

MC = (b/l)·x   荷载在C左

MC = (a/l)·(l−x)   荷载在C右

图形：三角形，C点竖距 yC = ab/l

简支梁剪力影响线

FQC = −x/l   荷载在C左

FQC = (l−x)/l   荷载在C右

图形：两段平行线，C处有突变

⚠️ 剪力影响线在截面处有突变，弯矩影响线连续

三、机动法作影响线

理论基础：虚功原理

Z(x) = −δP(x) / δZ

步骤

  1. 撤去与Z相应的约束，代以未知力Z → 使体系成为有一个自由度的机构
  2. 令机构沿Z正方向发生单位虚位移 → 作荷载作用点的竖向位移图 δP
  3. 位移图即为影响线形状，δZ以上为正，以下为负
方法原理特点
静力法平衡方程精确，可求数值
机动法虚功原理快速定性，适合判断最不利位置
💡 确定最不利荷载位置时，往往只需知道影响线轮廓，用机动法更便捷

四、影响线的应用

单个集中荷载

最不利位置：荷载作用在影响线竖距最大处

Zmax = FP · ymax

一组集中荷载

一般原则：把数量大、排列密的荷载放在影响线竖距较大的部位

临界荷载判别式

ΣFR左/a > ΣFR右/b  且  (ΣFR左−FPcr)/a < (ΣFR右+FPcr)/b

（或反之）

💡 简化理解：临界荷载是使"左密右疏"变"左疏右密"的那个荷载

五、绝对最大弯矩与包络图

绝对最大弯矩

移动荷载下梁内可能出现的弯矩最大值

  • 必定发生在某一集中荷载作用点
  • 使该荷载与合力关于梁中点对称
  • 逐个荷载试算，取最大值

包络图

各截面内力最大值连成的图形（弯矩包络图 + 剪力包络图）

💡 包络图用于设计，表示各截面可能承受的最大内力

📝 总结

一句话：影响线是研究移动荷载的工具，静力法列方程求精确值，机动法用虚功快速定性；利用影响线可确定最不利荷载位置和绝对最大弯矩。

⚠️ 易错点

  1. 影响线横坐标是荷载位置，不是截面位置
  2. 剪力影响线在截面处有突变，别画成连续线
  3. 结点荷载下影响线在结点间是直线，不是曲线
  4. 临界荷载判别式要分清左右段，别搞反不等号方向
  5. 绝对最大弯矩不一定在梁中点，要在某荷载作用点

第7讲 力矩分配法

2026-09-27

🔑 核心概念

  • 转动刚度 S：使杆端产生单位转角所需力矩
  • 分配系数 μ：分配力矩占总不平衡力矩比例
  • 传递系数 C：远端弯矩与近端弯矩之比
  • 固端弯矩：荷载引起的杆端弯矩
  • 不平衡力矩：结点处各杆固端弯矩之和

❓ 关键问题

  1. 转动刚度、分配系数、传递系数怎么算？
  2. 力矩分配法的基本步骤？
  3. 多结点力矩分配怎么操作？
  4. 力矩分配法与位移法有什么关系？
  5. 无侧移刚架怎么用力矩分配法？

一、三个核心参数

远端支承转动刚度 S传递系数 C
固定端4i1/2
铰支端3i0
定向滑动i−1
自由端0−

线刚度：i = EI/l

💡 记忆：远端固定4传递半，远端铰支3不传，远端滑动1反向传

二、分配系数

μij = Sij / ΣSik

性质：同一结点各杆分配系数之和 = 1

⚠️ 分配系数只与刚度比有关，与荷载无关

三、力矩分配法步骤

  1. 锁定：锁住所有刚结点，计算固端弯矩 MF
  2. 放松：选一个不平衡力矩最大的结点放松
  3. 分配：将 −M不平衡 按分配系数分配给各杆
  4. 传递：分配弯矩向远端传递（乘传递系数）
  5. 迭代：轮流放松各结点，反复迭代直到收敛
  6. 叠加：最终弯矩 = 固端 + 各轮分配 + 各轮传递
💡 通常 3~5 轮即可达到工程精度

四、力矩分配法 vs 位移法

比较项力矩分配法位移法
本质迭代法（渐近）精确法（解方程）
未知量不直接求位移求结点位移
适用连续梁、无侧移刚架所有结构
手算优势过程规范，易校核需解方程组

关系：力矩分配法是位移法的迭代版本

五、多结点力矩分配

核心策略：逐次放松，交替进行

⚠️ 相邻结点不能同时放松！

加速收敛技巧：

  • 从不平衡力矩最大的结点开始
  • 对称结构可取半结构
💡 每次传递后不平衡力矩逐渐减小，因为 |C| ≤ 1，必然收敛

📝 总结

一句话：力矩分配法是位移法的迭代版本，通过"锁定→放松→分配→传递"的循环逐次逼近精确解。

📌 核心公式

S固定=4i, S铰支=3i, S滑动=i

C固定=1/2, C铰支=0, C滑动=−1

μij = Sij/ΣSik

⚠️ 易错点

  1. 分配系数之和必须 = 1
  2. 放松时分配的是 −不平衡力矩（负号！）
  3. 相邻结点不能同时放松
  4. 多结点要轮流放松

混凝土第2讲 受弯构件正截面承载力

2026-10-16

🔑 核心概念

  • 单筋矩形两套流程：已知M求As / 已知As求Mu
  • 双筋截面：x>ξb·h0 且截面不能放大时引入 As′
  • x<2a′ 处理：《混规》6.2.14，对受压筋取矩
  • T形两类判别：中和轴在翼缘内=第一类
  • 翼缘计算宽度 bf′：《混规》表5.2.4 取最小值

❓ 关键问题

  1. 配筋式 x 的求法和复核式差在哪？
  2. 受压钢筋充分利用的前提条件是什么？
  3. x<2a′ 时公式里为什么出现 h−as−as′？
  4. 配筋计算和截面复核的判别式各用哪个？
  5. bf′ 按哪三个因素确定？

一、单筋矩形截面：两类计算流程

配筋计算（已知M求As）：

x = h0 − √[h0² − 2γ0M/(α1·fc·b)]，要求 x ≤ ξb·h0

As = α1·fc·b·x / fy，再校核 As ≥ ρmin·b·h

截面复核（已知As求Mu）：

x = fy·As/(α1·fc·b)；x>ξb·h0 时取 x=ξb·h0

Mu = α1·fc·b·x·(h0 − x/2)，验算 γ0·M ≤ Mu

⚠️ x>ξb·h0 且截面/混凝土等级不能改 → 转双筋；抗震计算把 γ0M 换成 γRE·M（γRE=0.75 受弯）

二、双筋矩形截面（《混规》6.2.10）

ΣN=0：α1·fc·b·x + fy′·As′ = fy·As

ΣM=0：γ0·M ≤ α1·fc·b·x·(h0−x/2) + fy′·As′·(h0−as′)

适用前提：x ≤ ξb·h0 且 x ≥ 2a′（保证受压筋屈服、应力取 fy′）

配筋流程：M1 = γ0M − fy′As′(h0−as′) → 用 M1 按单筋求 x → As = (α1·fc·b·x + fy′·As′)/fy

⚠️ 抗震框架梁端截面附加要求：x ≤ 0.25h0（一级）、x ≤ 0.35h0（二、三级）

三、x<2a′ 的处理（《混规》6.2.14）

x<2a′ → 受压筋应变小、不屈服 → 近似取 x=2a′，弯矩对受压筋合力点取矩：

配筋：As = γ0M / [fy·(h − as − as′)]

复核：Mu = fy·As·(h − as − as′)（抗震再除 γRE）

四、T形截面两类判别与计算（《混规》6.2.11）

判别：中和轴在翼缘内（x ≤ hf′）= 第一类，按宽 bf′ 的矩形算；中和轴入肋（x>hf′）= 第二类

配筋式判别：α1·fc·bf′·hf′·(h0−hf′/2) ≥ γ0M → 第一类

复核式判别：α1·fc·bf′·hf′ ≥ fy·As → 第一类

第二类配筋：M1 = α1·fc·(bf′−b)·hf′·(h0−hf′/2)；x = h0 − √[h0² − 2(γ0M−M1)/(α1·fc·b)]

As = α1·fc·[b·x + (bf′−b)·hf′] / fy

箱形、工字形、槽形、倒L形均可等效为T形处理

五、翼缘计算宽度 bf′（《混规》表5.2.4）

三因素控制，取最小值：①计算跨度 l0：肋形梁 l0/3，倒L形肋形梁 l0/6；②梁肋净距 sn：b+sn（肋形）、b+sn/2（倒L）；③翼缘高度 hf′/h0：≥0.1 时 b+12hf′；0.05~0.1 时肋形 b+12hf′/独立梁 b+6hf′；<0.05 时肋形 b+12hf′/独立 b+5hf′

影响翼缘有效性的本质：离肋越远的翼缘参与受力越差（剪滞）

⚠️ 独立梁（不与楼板整浇）受压翼缘可能沿纵肋开裂时，计算宽度只取 b

📝 总结

一句话：正截面承载力全是"两个平衡方程+适用条件"的变体——单筋是母版（x≤ξb·h0、As≥ρmin·bh）；双筋加一项 fy′As′(h0−as′)，x≥2a′ 才计受压筋，否则对受压筋取矩；T形先判类型，第一类当 bf′ 宽的矩形，第二类从弯矩里先扣掉翼缘挑出部分 (bf′−b)hf′，bf′ 查表5.2.4取最小。

⚠️ 易错点

  1. 配筋式与复核式的 T形判别式不同（一个带 h0−hf′/2，一个不带）
  2. x<2a′ 用 h−as−as′ 力臂，不是 h0−as′
  3. 抗震端截面 x≤0.25/0.35h0 是延性要求，比 ξb 严
  4. bf′ 三种情况取最小值，不是最大值

二、螺旋箍柱（6.2.16）

N ≤ 0.9(fc·Acor + f′y·A′s + 2α·fyv·Ass0)，Ass0=π·dcor·As′1/s，α=1.0，dcor=d−2c−2d螺旋

多层框架：现浇楼盖 底层 1.0H、其余 1.25H；装配式 1.25H / 1.5H

单层排架（刚性屋盖）：无吊车单跨 1.5H、多跨 1.25H；上下端有支点轴压构件 l0=1.1l

四、偏压判别与对称配筋（6.2.17）

e0=M/N，ea=max(20, h/30)，ei=e0+ea；先按 6.2.4（附录B）判断二阶效应是否放大 M

对称配筋：x = γ0N/(α1·fc·b)（抗震用 γRE·N）；x≤ξbh0 大偏压，否则小偏压（6.2.17-8 重算 ξ，σs<fy）

⚠️ 算完必查柱一侧最小配筋 0.2%·bh——计算值经常不控制

五、柱斜截面（6.3.12）与 γRE

V ≤ [1.75/(λ+1)]ft·b·h0 + fyv(Asv/s)h0 + 0.07N；λ=M/(Vh0)，反弯点在层高内取 Hn/(2h0)，限 1.0~3.0；均布 1.5、集中(≥75%) a/h0

N>0.3fc·A 取 0.3fc·A；V ≤ 混凝土项+0.07N 时仅构造配箍（6.3.13）

正截面 γRE（11.1.6）：N/(fcA)<0.15 → 0.75；≥0.15 → 0.80

⚠️ 非抗震 +0.07N（有上限）；抗震公式 −0.2N（第8讲），别混

一句话：轴压看 φ 和 0.9，螺旋箍三重门槛+1.5Nl 封顶；偏压先算 ei 再判大小——对称配筋 x=γ0N/(α1fcb) 比 ξbh0，大偏压套 6.2.17、小偏压重算 ξ 并防背面；柱受剪记 λ 两种算法和 +0.07N（0.3fcA 封顶）。

  1. φ 查表用边长/直径不是 h0
  2. 螺旋箍 1.5Nl 上限漏用
  3. x<2a′ 要改 6.2.14
  4. γRE 按轴压比分档（0.15 界限）

一侧 ρmin = max(0.2%, 45ft/fy%)（8.5.1）；抗震 γRE=0.85

二、偏心受拉（6.2.23）

e0=M/N < h/2−as（N 作用在两排筋之间）→ 小偏拉；e0 ≥ h/2−as → 大偏拉

小偏拉：As = γ0N·e/[fy(h0−a′s)]，e = e0+h/2−a′s（对 A′s 合力点取矩）；求 A′s 对 As 取矩同理

大偏拉：形式同大偏压（有受压区），按 6.2.23-3/4

⚠️ 判别分界是 h/2−as（N 作用点位置），不是 ξb

三、纯扭承载力（6.4.4）

平衡扭转（雨篷梁）：扭矩与抗扭刚度无关，必须计算；协调扭转（框架边梁）：可仅构造增配

矩形 Wt = b²(3h−b)/6；T 形/工字形分块（腹板+翼缘），扭矩按各块 Wt 比例分配

T ≤ 0.35ft·Wt + 1.2√ζ·fyv·(Ast1/s)·Acor；ζ 纵筋与箍筋匹配系数，取 0.6~1.7（手算常设 1.0 再校核）

截面限制（6.4.1）：T/(0.8Wt) ≤ 0.25βc·fc（hw/b≤4）；Acor=箍筋中心线围合面积

四、弯剪扭叠加

箍筋：(Asv/s)总 = 受剪所需 + 受扭 2Ast1/s（扭矩由两侧肢承担）；纵筋=受弯+受扭 Ast（周边均布、四角必设）

剪扭相关性：βt=1.5/(1+0.5VWt/(Tbh0))，混凝土项分别折减后叠加（6.4.8~6.4.10）

⚠️ fyv>360 仍取 360（4.2.3 受剪/受扭/受冲切）

一句话：受拉构件"混凝土退场、钢筋说话"——轴拉全筋屈服、小偏拉两侧筋各自取矩；扭转三件套：Wt=b²(3h−b)/6 → T≤0.35ftWt+1.2√ζfyv(Ast1/s)Acor（ζ 0.6~1.7）→ 弯剪扭用 βt 折减、箍筋叠加 2Ast1/s、构造下限 0.28ft/fyv。

一级（全预应力）：标准组合 σck − σpc ≤ 0——受拉边不出现拉应力

⚠️ 组合选择高频考点：钢筋混凝土=准永久；预应力三级裂缝=标准组合

构造（9.1.11）：抗冲切箍筋 d≥6mm、间距 s≤min(h0/3, 100mm)？教材口径 s≤h0/3；弯起筋 d≥12mm、每向≥3根

⚠️ 已知Fl求箍筋：Asvu=(Fl−0.5ftηumh0)/(0.8fyv)，再按四周总肢数 n·Asv1≥Asvu 配筋

四、板柱节点不平衡弯矩（附录F + 抗震11.9.3）

节点传递不平衡弯矩 Munb 时，用等效集中反力：Fl,eq = Fl + τmax·um·h0（把锥体斜面化为临界截面垂直截面，Munb 产生的竖向剪应力线性分布，取 τmax 折算附加集中反力）

Munb 取对临界截面周长重心轴（轴2）的矩 = 对柱重心轴（轴1）的弯矩 + Fl 对该轴取矩；两弯矩同向取加、反向取减；计算系数 αo 按 F.0.2，中/边/角柱参数见图 F.0.1

边柱/角柱有悬臂板时：可能按边/角柱临界面，也可能按中柱锥体，计算比较取不利（F.0.4）

地震组合（11.9.3）：Fl,eq 乘增大系数——一、二、三级抗震等级分别取 1.7、1.5、1.3；配抗冲切钢筋时锥体以外截面按 6.5.4 式验算（um 取最外排筋外 0.5h0）

⚠️ 借鉴 ACI 318 方法；忽略临界截面水平剪应力（近似略去 h0³ 项）

五、局部受压（6.6）

机理：外围混凝土"套箍"→局部区三向受压→局压强度远高于轴压，提高随 Ab/Al 增大

βl=√(Ab/Al)；Ab（6.6.2）"同心、对称"：与局压面同重心，沿各边向外扩大有效距离不超过受压面短边 b（圆形承压板可沿周边扩大一倍直径）；边角局压 βl=1.0；算 βl 不扣除孔道面积

截面限制（6.6.1）：Fl ≤ 1.35βcβl·fc·Aln；βc：≤C50取1.0，C80取0.8（插值）

配置方格网/螺旋间接钢筋（6.6.3）：Fl ≤ 0.9(βcβlfc + 2α·ρv·βcor·fyv)Aln；α：≤C50取1.0，C80取0.85；βcor=√(Acor/Al)，Acor>Ab时取Ab；Acor≤1.25Al 时不考虑间接钢筋提高

ρv：方格网 (n1As1l1+n2As2l2)/(Acor·s)；螺旋式 4Ass1/(dcor·s)；长短向配筋相差过大受限时钢筋强度不能充分发挥

素混凝土局压（附录D.5.1）：ω 均布取1.0、梁/过梁端部支承（非均匀）取0.75；锚头下局压：预应力作荷载效应对不利时分项系数1.2（10.1.2）；牛腿局压见构造（8.2.2，第7讲）

⚠️ 2013二级真题：a=300、b=200 居中 → Ab=(300+2×200)×(3×200)=420000，βl=√(Ab/Al)=2.65

📝 总结

一句话：冲切 = 0.7βhftηumh0（um在h0/2处、η取η1η2小者、Fl扣锥体内荷载、洞口≤6h0要扣周长）；配抗冲切筋双控（1.2ft上限+0.5ft+0.8fyvAsvu+0.8fyAsbu·sinα，fyv≤360）；板柱节点有不平衡弯矩换 Fl,eq=Fl+τmax·um·h0、抗震乘1.7/1.5/1.3；局压 = βl=√(Ab/Al)（同心对称、边角取1.0）+ 截面限制1.35βcβlfcAln + 间接筋0.9(βcβlfc+2αρvβcor·fyv)Aln（Acor≤1.25Al不考虑）。

⚠️ 易错点

  1. Fl（荷载）与[F l]（承载力）混淆
  2. αs 中边角柱 40/30/20 与 βs 下限2 记混
  3. Fl 忘扣 q×锥体底面积
  4. βh/βc/α 三个插值系数张冠李戴
  5. Ab 各边扩大限短边b（圆形一倍直径），边角βl=1.0
  6. Acor≤1.25Al 仍乘 βcor 提高（不应考虑）
  7. fyv>360 未截断

基础题1：中柱 600mm×600mm，板有效高度 h0=355mm，方形柱的临界截面周长 um：

A. 3440mm　B. 3820mm　C. 4280mm　D. 4440mm

💡 查看答案

答案：B

um = 4×(bc+h0) = 4×(600+355) = 3820mm。（临界面在柱边外 h0/2，每边外扩 h0/2×2？每侧+ h0/2，周长 4×(600+2×h0/2)=4×(600+355)）

进阶题2：方形柱帽1600×1600 对板冲切，h0=210mm，um=7240mm，中柱。受冲切承载力系数 η：

A. 0.79　B. 1.00　C. 1.21　D. 1.43

💡 查看答案

答案：A

βs=1<2 取2 → η1=0.4+1.2/2=1.0；η2=0.5+40×210/(4×7240)=0.79；取小 → η=0.79。（2013上午11题同款）

考试热点题3：板柱结构中柱 N=1500kN（层间差值），板面均布荷载设计值 q=12kPa，柱600×600，h0=210mm。冲切力 Fl：

A. 1388kN　B. 1450kN　C. 1488kN　D. 1500kN

💡 查看答案

答案：C

锥体底 (0.6+2×0.21)²=1.0404m²；Fl=1500−12×1.04≈1488kN。注意扣的是冲切锥体底面（荷载面积外扩2h0）内板荷载。

进阶题4：大截面构件中部矩形局部受压面 a×b=300×200mm，无孔洞、忽略边距。验算时 βl：

A. 1.73　B. 2.16　C. 2.65　D. 3.00

💡 查看答案

答案：C

Ab=(a+2b)×(b+2b)=(300+400)×600=420000mm²；Al=60000mm²；βl=√(420000/60000)=√7≈2.65。（2013上午13题改编）

概念题5：关于局部受压，下列说法错误的是：

A. 计算底面积Ab与局压面积Al同心对称　B. 边角局部受压时 βl=1.0　C. 圆形承压板可沿周边扩大一倍直径　D. Acor 大于 Ab 时仍按实际 Acor 取值

💡 查看答案

答案：D

Acor>Ab 时只能取 Ab（保证间接钢筋充分发挥且偏安全）；另 Acor≤1.25Al 时不考虑间接钢筋提高。
